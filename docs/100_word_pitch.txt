The Smart Market Watchlist is an end-to-end financial intelligence engine built with FastAPI, React, and SQLite to solve a core problem: surfacing meaningful price shifts without daily noise.Instead of tracking fixed 24-hour deltas, the backend calculates relative movements against user-captured baseline snapshots. A category-weighted anomaly engine dynamically flags shifts using custom sensitivity thresholds for High Beta ($\pm 3.0\%$), Large Cap ($\pm 1.2\%$), and Stable ETFs ($\pm 0.75\%$).To ensure system resilience during third-party API outages, the application automatically falls back to database-cached prices with visual warning badges. Key technical highlights include JWT authentication, interactive simulation controls, and Recharts analytics.
